# Звуковой банк

`GeneralUser-GS.sf2` (v2.0.3) не хранится в git из-за размера (32 МБ). Скачать и положить сюда:

https://github.com/mrbumpy409/GeneralUser-GS/raw/main/GeneralUser-GS.sf2

Лицензия — `LICENSE.txt` рядом.

Программа ищет первый `.sf2` по порядку:
1. путь из настроек;
2. `%APPDATA%\com.musicgamepad.app\sounds\`;
3. папка `sounds\` рядом с .exe;
4. эта папка — только на машине, где собирали (путь вшит при сборке).
